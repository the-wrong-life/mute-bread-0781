# 玉衡返工记录（2026-11-10 第二轮）

本文件记录本次针对首页主视觉「玉衡」的返工实验。所有结论都限定在本轮渲染条件下，换相机、换灯光、换渲染器都需要重新验证。

## 一、本轮目标

1. 衔尾蛇改为围绕玉球的完整外圈轮廓，蛇头落在画面右上方。
2. 铜环补实体厚度、可辨认的倾斜投影，与蛇环保持间距。
3. 用对照渲染定位球体中央的白斑来源。
4. 玉牌移到画面右下。

## 三、白斑诊断（对照渲染）

脚本先 bpy.ops.wm.read_factory_settings(use_empty=True) 清空场景，打印 EMPTY-OBJECTS 0 确认没有残留默认 Cube/相机/灯光，再导入 GLB 得到 44 个对象，全部是本项目自有命名。

固定相机 (0,-10,0.35)、固定曝光，分别输出七张对照图：

| 对照图 | 结果 |
|---|---|
| diag-nokernel（关闭内核自发光） | 与全开几乎相同 |
| diag-all | 中央有不规则浅白区 |
| diag-only-rim（只留轮廓灯） | 整体暗绿，无白斑 |
| diag-only-key / only-back / only-fill | 白斑随主光与补光强度变化 |

结论：白斑不是内核自发光造成的，而是球壳的 Transmission 直接把暖白背景透了出来。球心视线路径最短、吸收最少，因此中央读成一片不规则浅白。

## 四、关键教训

### 不要给球壳加 Solidify

球面本身是闭合曲面，Volume Absorption 会在球内生效。一旦加厚成双层壳（本轮试过 0.085），体积被限制在壁内、路径太短，吸收几乎失效，球心直接透出背景白，反而更像玻璃泡。

### 深色背景下 Transmission 表达不了玉

薄了变白玻璃、厚了发暗，反复调参跳不出塑料感。本轮最终改走「实心浅青玉 + 强次表面散射」：Transmission 降到 0.12 只留边缘水头，主体靠 Subsurface Weight 0.9 / Scale 0.5 表现玉肉。

### 砖格贴图必须在 UV 上按片数给

UV 按弧长给（t*3.5）会把鳞片沿管长拉成细条纹；按片数给（t*20）才是规整甲片。砖格本身再旋转 45° 成菱形，比横竖方砖更接近覆瓦感。

### 蛇头不能沿用蛇身的砖格材质

蛇身用砖格表达甲片，但蛇头是球体 UV，砖格在头上只铺到一两块，读成整块金铜色，于是头和身颜色断开、像「绿管子插了块金石头」。本轮在渲染侧按对象名为 serpent-skull / serpent-snout / serpent-jaw 单独分配青玉材质。

## 五、渲染参数（可复现）

相机 (0,-10,0.35)，92 mm；1400×1400；Cycles CPU 128 samples + denoise；AgX / Medium High Contrast；film_transparent=True。

球壳 mat-jade-shell：Base (0.30,0.62,0.48)、Roughness 0.10、Transmission 0.12、IOR 1.55、Coat 0.5、SSS 0.9 / Radius (0.42,0.80,0.58) / Scale 0.5、Volume Absorption Color (0.16,0.52,0.36) Density 1.4。

内核 mat-kernel：Base (1.0,0.95,0.86)、Emission (1.0,0.88,0.66) 强度 2.8。

蛇身 mat-serpent：砖格 Scale 1.6、Mortar 0.014、UV 旋转 45°，甲片 Color1 (0.10,0.30,0.23) / Color2 (0.07,0.22,0.17)，砖缝金铜 (0.66,0.48,0.20)。

复现命令：blender.exe -b --python tools/blender/render-yuheng.py

GLB 由 node _work/nova-export-glb.mjs 从 /lab 页面导出。

## 六、仍未达标的部分（如实记录）

1. 蛇头形态：目前读成「扁平勺状 + 尖吻」，没有清楚的下颌开合、眼窝与咬合关系。这是几何建模层面的问题，靠材质与渲染参数调不出来，需要重做蛇头几何。
2. 鳞片质感：菱形砖格仍偏「藤编」，缺少真实蛇鳞的覆瓦层次与大小渐变。
3. 球体内部光核：参考图中央有明确的暖白光珠，本轮球心偏均匀浅青。
4. 铜环刻度：正面投影下刻度齿几乎不可辨。
