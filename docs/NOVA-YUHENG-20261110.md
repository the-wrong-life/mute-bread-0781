# 玉衡返工记录（2026-11-10 第二轮）

本文件记录本次针对首页主视觉「玉衡」的返工实验。所有结论都限定在本轮渲染条件下，换相机、换灯光、换渲染器都需要重新验证。

## 一、本轮目标

1. 衔尾蛇改为围绕玉球的完整外圈轮廓，蛇头落在画面右上方。
2. 铜环补实体厚度、可辨认的倾斜投影，与蛇环保持间距。
3. 用对照渲染定位球体中央的白斑来源。
4. 玉牌移到画面右下。

## 二·五、比例命名（统一口径）

同一组数字在不同文档里被叫成"半径/直径/宽度"，造成过误读。此后一律按下列命名引用，不再混用：

| 符号 | 含义 | 数值 |
|---|---|---|
| `Rball` | 玉球外半径 | 1.000 |
| `Rring_in` | 铜环内半径 | 1.005 |
| `Rring_out` | 铜环外半径 | 1.105 |
| `Wring` | 铜环带宽 = `Rring_out − Rring_in` | 0.100 |
| `Tring` | 铜环轴线方向厚度 | 0.130 |
| `Rsnake` | 蛇环平均半径 | 1.140 |
| `Ratio` | 铜环外半径 / 玉球半径 | **1.105** |

关于历史比值：旧版铜环是 `CylinderGeometry(1.30, 1.30, 0.072, openEnded)`，两处 1.30 都是**半径**，因此旧的 `Ratio = 1.30`，新的 `Ratio = 1.105`，铜环相对玉球是**变小**了。

此前文档与回报里写过「上一轮把半径当成了直径」，这句话是错的，已删除：旧参数并不是直径，只是当年把 1.30 直接称作"直径是球径 1.30 倍"的表述含混。现在只用 `Ratio` 一个口径比较。

## 三、白斑诊断（对照渲染）

脚本先 bpy.ops.wm.read_factory_settings(use_empty=True) 清空场景，打印 EMPTY-OBJECTS 0 确认没有残留默认 Cube/相机/灯光，再导入 GLB 得到 44 个对象，全部是本项目自有命名。

固定相机 (0,-10,0.35)、固定曝光，分别输出七张对照图：

| 对照图 | 结果 |
|---|---|
| diag-nokernel（关闭内核自发光） | 与全开几乎相同 |
| diag-all | 中央有不规则浅白区 |
| diag-only-rim（只留轮廓灯） | 整体暗绿，无白斑 |
| diag-only-key / only-back / only-fill | 白斑随主光与补光强度变化 |

结论（按本轮对照，只覆盖上述模型与光照条件）：
1. 关闭内核自发光后画面几乎不变 → **可以排除内核自发光是该白斑的主要来源**。
2. 白斑随主光、背光、补光强度变化，随轮廓灯则消失 → 它来自照明经球壳的反射与透射，不是自发光泄漏。
3. 至于是哪一项主导，本轮证据不足以定论，**需要继续核查**：镜面/菲涅尔反射、Transmission 透出的背景、以及 Volume Absorption 的实际吸收量三者都会落在这个区域，后续应用单变量对照（固定相机与曝光，每次只改一组）继续分离。

**一处此前的错误解释，在此更正**：本文早期版本写过「球心视线路径最短、吸收最少」。这在几何上是错的——对实心球而言，穿过球心的视线沿直径行进，是**最长**的光程（2R）；越靠近轮廓的弦越短（边缘相切时趋于 0）。因此如果体积吸收占主导，中央应当最**暗**而不是最亮。观测到的中央偏亮，说明该处不是吸收主导，而是反射与背景透射占优。这一条只作假设记录，仍需上文的单变量对照验证。

## 四、关键教训

### 不要给球壳加 Solidify

球面本身是闭合曲面，Volume Absorption 会在球内生效。一旦加厚成双层壳（本轮试过壁厚 0.085），体积被限制在壁内、光程太短，吸收几乎失效，球心直接透出背景白，反而更像玻璃泡。

限定条件：这是在「实心球 + Volume Absorption Density 1.4 + 暖白世界背景 + Transmission 0.12」这组参数下的观察，不是引擎或物理上的通用限制。换配方（例如把吸收放在球壳材质、或改用纯 SSS 不做体积吸收）需要重新测试，不能直接套用本结论。

### 深色背景下 Transmission 表达不了玉

薄了变白玻璃、厚了发暗，反复调参跳不出塑料感。本轮最终改走「实心浅青玉 + 强次表面散射」：Transmission 降到 0.12 只留边缘水头，主体靠 Subsurface Weight 0.9 / Scale 0.5 表现玉肉。

### 砖格贴图必须在 UV 上按片数给

UV 按弧长给（t*3.5）会把鳞片沿管长拉成细条纹；按片数给（t*20）才是规整甲片。砖格本身再旋转 45° 成菱形，比横竖方砖更接近覆瓦感。

### 蛇头不能沿用蛇身的砖格材质

蛇身用砖格表达甲片，但蛇头是球体 UV，砖格在头上只铺到一两块，读成整块金铜色，于是头和身颜色断开、像「绿管子插了块金石头」。本轮在渲染侧按对象名单独分配青玉材质；蛇头几何改为放样后，对象名已变为 serpent-upper-jaw / serpent-lower-jaw / serpent-mouth / serpent-eye-socket-{l,r}，渲染脚本需同步更新。

## 五之二、蛇头结构返工（2026-11-10 晚）

上一版蛇头由「上颌半壳 + 下颌半壳」两块放样体拼合。实测无论在正面、四分之三还是侧视，接缝都读成"蚌壳/夹板"，加上头部整体缩放不匹配，读成"手电筒""鸭嘴""头盔"。

本轮改为**单一闭合放样体 + 压出的嘴缝**：

- `headSections` 共 11 段，x 从 −0.46（埋进蛇身管口）到 0.37（吻尖），最宽处 w 0.172 在 x=−0.02，z 向比 y 向宽约 1.6 倍（蛇头扁宽），中心线 cy 从 +0.012 单调降到 −0.030，形成吻端下垂。
- 头部网格对象名 `serpent-upper-jaw`（沿用旧名，避免渲染脚本材质映射失效）。
- 嘴缝：沿每段截面的最大宽度线（y = cy − 0.06h，z = w − seamR + 0.004）生成 `CatmullRomCurve3`，用 `TubeGeometry` 半径 0.008 的双侧细管压出暗缝；左右各一条，`serpent-mouthline-l/r`，材质 `mat-serpent-mouth` 色 #2a1a10。
- 鼻孔：吻背两侧 `serpent-nostril-l/r`，半径 0.012 的扁球，位置 (0.275, 0.014, ±0.030)。
- 眼睛参数必须跟着截面走：`eyeX 0.06` 处插值得 w 0.1608 / h 0.0996 / cy −0.0092，θ 1.14，眼半径 0.034，沿法线外移 0.006。**教训：改了 headSections 就必须重算 eyeW/eyeH/eyeCy，否则眼球会浮在头外。**
- 颈套筒 `serpent-neck`：`CylinderGeometry(0.106, 0.096, 0.30, 28)` + rotateX(π/2)，沿 −fwd 放在 tip − fwd·0.06，盖住蛇身管的平端面。**注意它必须写在 `tip`/`fwd` 定义之后**，否则引用未初始化变量。

实测结论：接缝问题解决，眼窝/眼球/嘴缝/鼻孔都能在四分之三视图中读出；但头部整体仍是光滑长楔形，缺少鳞片、眉脊与颊窝，放大看仍不像真实蛇头。

## 八、鳞片样段：几何甲片方案（第 4 条）

现有方案是砖格贴图 + bumpMap（法线方案），远看菱形网、近看像编织袋。本轮新增**几何甲片**作为同机位对照：

- 函数 `buildScaleSample(curve, t0, t1, radiusAt, hi)`，参数 rows 26 / cols 12 / segA 6 / segB 5（低画质折半）。
- 甲片长度按弧长给：`step = len*(t1-t0)/rows`，片长 `step*1.45`（重叠 45%）；片宽 `周长/cols*1.55`；片高 `r*0.30`。
- 逐行错位半个步距（`(j + (i%2)*0.5)/cols`），读成覆瓦而不是方格阵。
- 尺寸随蛇身半径缩放（颈部大、尾部小），方向取"顺着蛇身走"的局部坐标架（切向 × 径向）。
- 合并成单个网格 `serpent-scales-sample`，材质 `mat-serpent-scale`（#12402e，roughness 0.24，metalness 0.42），落在曲线 t 0.66–0.80 一段。

这样 GLB 仍是**单一模型**（符合第 1 条），样段与其余部分在同一张图里可直接对比。

## 九、球壳参数对照（第 3 条）

灯具形状从方形面光改为 **DISK**（方光在光滑玉壳上反射出矩形白斑，这是"矩形大白反光"的直接来源）。三档透光参数同机位（`web` 相机）渲染：

| 组 | NOVA_TRANS | NOVA_DENS | 文件 |
|---|---|---|---|
| 基准 | 0.36 | 1.7 | `c42-yuheng-web-web.png` |
| 高透 | 0.62 | 0.75 | `t62-yuheng-web-web.png` |
| 低透 | 0.24 | 1.9 | `t24-yuheng-web-web.png` |

**像素量化（PIL，逐像素 RGB 绝对差）：**

- t62 vs 基准：`mean_abs_diff = 2.38`（0–255 尺度，约 0.9%），max 176
- t24 vs 基准：`mean_abs_diff = 1.02`（约 0.4%），max 168

结论（限定本轮条件）：**在 Transmission 0.24–0.62 区间内，Transmission 不是玉壳外观的主导变量**，外观主要由 SSS、噪声色阶与体积吸收共同决定。调整这三档肉眼看不出差别，说明继续在这一维度扫参数没有收益，下一步应改 SSS Scale 与噪声色阶的对比。
